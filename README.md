# SEO Кластеризатор (Калуга)

Скрипт для очистки и кластеризации семантического ядра с фокусом на регион "Калуга".

## Функционал
1. **Гео-фильтрация**: Оставляет запросы с упоминанием "Калуга" и запросы без гео. Удаляет другие города (Москва, СПб и т.д.).
2. **Фильтр частотности**: Удаляет запросы с частотой ниже заданного порога.
3. **Очистка мусора**: Удаляет информационные и паразитные запросы ("скачать", "бесплатно", "реферат" и т.д.).
4. **Кластеризация**: Группирует оставшиеся запросы по смыслу используя TF-IDF и K-Means.

## Установка зависимостей
```bash
pip install pandas scikit-learn numpy
```

## Как использовать
1. Подготовьте файл `keywords.csv` со столбцами:
   - `keyword` (обязательно) - текст запроса
   - `freq` (опционально) - частотность запроса
   
   *Или просто список запросов в текстовом файле.*

2. Запустите скрипт:
```bash
python clusterizer.py
```

3. Результат сохранится в файле `clusters_result.csv`.

## Настройка
Откройте `clusterizer.py` и измените переменные в блоке `КОНФИГУРАЦИЯ`:
- `MIN_FREQUENCY`: минимальная частота для оставления запроса.
- `STOP_WORDS`: список слов для удаления мусорных фраз.
- `other_cities`: список городов, которые нужно исключить.
